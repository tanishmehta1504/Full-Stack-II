Backend Architecture & Design Spec

Demonstrates Spring Boot 3.3 Layered Architecture & Request Lifecycle:

1. HTTP Client Request ➔ Injects X-Correlation-Id header
2. CorrelationIdFilter & MDC ➔ Puts correlation ID into org.slf4j.MDC
3. CorsConfig Filter ➔ Evaluates Access-Control-Allow-Origin: *
4. PostController (@RestController) ➔ Receives DTO & applies Bean Validation
5. GlobalExceptionHandler (@RestControllerAdvice) ➔ Intercepts exceptions & returns standardized ApiResponse<T> envelope
6. PostRepository (Spring Data JPA) ➔ Persistence layer for entities
